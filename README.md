# Drishti 🎃

A floating macOS overlay inspired by the *drishti* ritual for warding off the evil eye. A pumpkin with a burning camphor flame floats above whatever is on your screen. Touch it with the mouse and it follows the pointer. Bring it down to the bottom of the screen and it smashes into pieces, which settle, fade, and the app quits.

Written in Swift with SpriteKit. It runs fully offline.

## Run it

1. Double-click `Build_Drishti_V5_Mac.command`.
2. It builds the app and puts it on your Desktop.
3. Double-click the app.

Needs Xcode command-line tools to build. There are no on-screen controls during the ritual.
