DRISHTI V4 FLOATING PUMPKIN
===========================

This version follows your latest direction:

- No app UI on screen.
- Only a realistic pumpkin with realistic camphor flame is visible.
- It opens as a transparent floating overlay.
- When the mouse touches the pumpkin, it automatically starts tagging along with the pointer.
- No separate select/click step.
- No default 3-round counter.
- The user can move it freely in any direction and then bring it to the bottom of the screen.
- On bottom impact, the pumpkin breaks into visible pieces.
- The broken pieces remain visible on the bottom for about 2–3 seconds.
- Then everything disappears.

FILES
- Drishti_V4_FloatingPumpkin.html
- macOS/Build_Drishti_Floating_Pumpkin_Mac.command

MAC USE
1. Open the macOS folder.
2. Double-click Build_Drishti_Floating_Pumpkin_Mac.command
3. It creates 'Drishti Floating Pumpkin.app' on your Desktop.
4. After that, just double-click the app.

HIDDEN CONTROLS
- ESC = close
- R = reset

NOTES
- The HTML file is a fallback preview.
- The best experience is the native Mac app, because it stays floating above whatever photo or social media window is already open.
